# 🐍 Fase 0 — Python Intermedio (Base Sólida)

Repositorio dedicado al aprendizaje de Python intermedio, enfocado en escribir código limpio, organizado y escalable como preparación para proyectos más avanzados en desarrollo de software e inteligencia artificial.

## 📚 Temas

- Programación Orientada a Objetos (POO)
- Entornos virtuales (`venv`, `conda`)
- Gestión de dependencias con `pip`
- Estructura profesional de proyectos
- Manejo de errores y logging
- Tipado con `typing`
- NumPy
- Pandas
- Docker

## 🛠️ Proyectos

- Sistema de registros
- Procesamiento de datos
- Pipeline simple de datos
- Lectura y limpieza de datasets

## 📂 Estructura del proyecto

```text
.
├── main.py
├── README.md
├── requirements.txt
├── src/
│   ├── models/
│   ├── services/
│   ├── utils/
│   └── data/
└── tests/
```

## 🚀 Objetivos

- Aplicar buenas prácticas de programación.
- Crear proyectos organizados y mantenibles.
- Manejar dependencias correctamente.
- Procesar datos con NumPy y Pandas.
- Preparar una base sólida para las siguientes fases.
